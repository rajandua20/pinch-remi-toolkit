MCP pre-flight (before you present)

The foundation — the first MCP server for Pinch, 22 tools (13 read · 9 confirm-guarded write). Each check takes 5 seconds.

  • Live — curl https://pinch-mcp-238547086112.australia-southeast1.run.app/healthz → {"ok":true}
  • Manifest — curl …/meta → toolCount: 22 + a toolsHash (20 / no hash = old revision).
  • Confirm-guard — a write tool called without confirm returns a preview and makes no API call; the public endpoint refuses live; refunds are capped.
  • Per-business keys — LyboAI → Integrations → MCP Server → Test → 22 tools, authenticated as that org's own merchant.
  • No card / bank field in any of the 22 tool schemas — capture happens only on Pinch's hosted page.
